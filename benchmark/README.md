## 复现

规则评测（结果写入新文件，程序拒绝覆盖已有报告）：

```powershell
mvn -f backend/pom.xml -Dtest=RuleEvaluationTest "-Devaluation.output=<新文件路径>.json" test
```

全量测试：

```powershell
mvn -f backend/pom.xml test   # 78 项，使用 H2，无需 MySQL
```

真实模型评测默认跳过（需显式 opt-in 且产生真实调用费用），详见 `P1-2-真实模型评测记录.md`。
