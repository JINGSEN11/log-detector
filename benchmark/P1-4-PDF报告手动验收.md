# P1-4 PDF 报告手动验收

## 功能与限制

在事件详情点击“导出 PDF 报告”，保存文件 `event-{事件ID}.pdf`。报告包含事件概览、最新研判来源和时间、攻击链、建议、证据表、规则统计；日志与研判内容经现有脱敏器处理。通过 PDFBox 和随依赖打包的 Noto Sans SC 字体生成，按页面嵌入字形子集。字体资源来自 Maven 包 `com.helger.font:ph-fonts-noto-sans-sc:5.0.4`，字体许可 SIL OFL 1.1（字体包内 `fonts/ttf/NotoSansSC/OFL.txt`），该资源包的代码许可及声明包含在依赖包内。PDFBox 为 Apache 2.0。

此 PDF 按普通 PDF 实现，不声明 PDF/A 合规。字符无法由字体编码时显示 `?`；长内容按字符换行并在跨页时续接。对于大量证据生成需要一定内存及时间，尚未做性能基准。

## 启动

在项目根目录按既有方式启动。Docker 环境需要重新构建应用：

```powershell
docker compose up -d --build backend frontend
```

该命令会重建应用容器但不删除数据库卷，请先保存正在进行的工作。未执行此命令时，浏览器仍可能加载旧版本。

## 操作步骤

1. 登录系统，进入“规则检测与事件”，任选事件点击“查看证据”。
2. 点击“导出 PDF 报告”，确认下载的文件名为 `event-事件ID.pdf`，用浏览器或 PDF 阅读器打开。
3. 检查中文显示、事件概览、攻击链、建议、证据表和规则统计，并与同事件 Markdown 报告核对。无研判事件应显示暂无研判记录；有研判事件应展示最新来源、攻击链及建议。
4. 选择包含长 URL 或较多证据的事件再导出，检查单元格内长文本换行、跨页续接、表头、页面边界和末尾内容完整性。确认脱敏原始行没有泄露实际密码/token。不要将真实凭据加入测试日志。
5. PDF 阅读器中查看“文档属性 → 字体”，检查 Noto Sans SC 显示为嵌入或嵌入子集；复制中文到文本编辑器，检查文本可读。阅读器显示方式可能不同。
6. 退出登录后直接访问该 PDF 接口应被拒绝；导出成功后用管理员账号查看审计中 `EVENT_PDF_EXPORT`。同时回归 CSV 与 Markdown 按钮。
